# Python Katas | Lógica y Fundamentos de Programación

## 📌 Descripción del proyecto

Este repositorio recoge la resolución de una serie de ejercicios prácticos (*katas*) de Python, desarrollados como parte de mi formación en Data Analytics en ThePower.

Una kata es un ejercicio de programación diseñado para mejorar las habilidades de resolución de problemas mediante la práctica y el perfeccionamiento de técnicas de codificación.

El objetivo de este proyecto es aplicar los conocimientos adquiridos durante el módulo de Python, desde los fundamentos del lenguaje hasta conceptos de programación funcional, gestión de excepciones y programación orientada a objetos.

Los ejercicios plantean diferentes problemas que permiten trabajar la lógica de programación, la manipulación de datos y la implementación de soluciones mediante Python.

## 🎯 Objetivos del proyecto

- Desarrollar el razonamiento lógico y la capacidad de resolución de problemas.
- Aplicar los tipos de datos básicos y las funciones incorporadas de Python.
- Utilizar estructuras de datos como listas, tuplas, diccionarios y conjuntos.
- Practicar estructuras condicionales y de iteración.
- Crear funciones con parámetros, argumentos y valores de retorno.
- Trabajar con expresiones `lambda` y funciones como `map()`, `filter()` y `reduce()`.
- Comprender la recursividad y la gestión de excepciones.
- Introducir la programación orientada a objetos mediante clases, atributos y métodos.
- Utilizar módulos y librerías de Python.
- Aplicar buenas prácticas mediante la organización del código, comentarios y pruebas.

## 🛠️ Tecnologías y herramientas

- **Python 3:** lenguaje de programación utilizado para resolver las katas.
- **Visual Studio Code:** entorno de desarrollo y edición del código.
- **Jupyter Notebook:** ejecución individual de ejercicios y comprobación de resultados.
- **GitHub:** alojamiento y presentación del proyecto.

Se han utilizado principalmente funciones integradas de Python y módulos de su biblioteca estándar.

## 🚀 Cómo ejecutar el proyecto

Para consultar y ejecutar los ejercicios:

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Seleccionar un intérprete de Python 3.
4. Abrir el archivo `KATAS_Project_python.ipynb`.
5. Ejecutar las celdas individualmente para consultar las soluciones y comprobar los resultados.

Alternativamente, el código se encuentra disponible en el archivo `KATAS_Project_python.py`, que puede ejecutarse desde una terminal.

**En Windows, utilizando el lanzador de Python:**

```powershell
py KATAS_Project_python.py
```

**En sistemas donde Python esté disponible mediante el comando `python`:**

```bash
python KATAS_Project_python.py
```

Algunos ejercicios utilizan `input()`, por lo que requieren introducir datos durante su ejecución.

El archivo `.py` se ha comprobado mediante una verificación de sintaxis y una ejecución completa con valores de prueba.

## 🔎 Metodología de trabajo

El proyecto se ha desarrollado de manera progresiva, siguiendo una metodología centrada en la práctica y la comprensión de los conceptos de Python.

### 1. Interpretación de los ejercicios

Lectura de los enunciados para identificar los objetivos, las condiciones y las herramientas necesarias para resolver cada problema.

### 2. Planteamiento e implementación

Desarrollo de las soluciones utilizando los conocimientos del módulo, aplicando funciones, estructuras de datos, condicionales, bucles y otros recursos de Python.

### 3. Ejecución y comprobación

Ejecución individual de las katas en Jupyter Notebook, utilizando diferentes ejemplos para comprobar el comportamiento de las funciones y los resultados obtenidos.

### 4. Identificación y corrección de errores

Revisión de errores de sintaxis, referencias a variables, indentación, lógica y ejecución, realizando los ajustes necesarios para mejorar las soluciones.

### 5. Organización y documentación

Organización de los ejercicios y sus comentarios explicativos en el código, exportación del notebook a un archivo `.py` y elaboración de esta documentación para su publicación en GitHub.

## 💡 Principales aprendizajes

Este proyecto me ha permitido consolidar los conocimientos fundamentales de Python mediante su aplicación a ejercicios prácticos de distinta complejidad.

Entre los aspectos más relevantes destacaría:

- **Lógica de programación:** estructurar soluciones utilizando condiciones, iteraciones y operaciones con distintos tipos de datos.
- **Funciones:** trabajar con parámetros, argumentos y valores de retorno para organizar el código.
- **Programación funcional:** comprender y utilizar expresiones `lambda` y funciones como `map()`, `filter()` y `reduce()`.
- **Gestión de errores:** identificar excepciones y aplicar mecanismos para controlar entradas y operaciones no válidas.
- **Programación orientada a objetos:** iniciarme en la creación de clases y objetos, comprendiendo el papel de `self`, `__init__`, los atributos y los métodos.

Los ejercicios relacionados con la programación orientada a objetos han representado uno de los mayores retos, especialmente por la necesidad de comprender cómo interactúan las distintas partes de una clase.

La práctica, la revisión de errores y la repetición de conceptos han sido importantes para avanzar a lo largo del proyecto.
